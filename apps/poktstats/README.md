# POKT Stats applet for Tidbyt

Displays the current USD/POKT token price from CoinGecko's public API. The price is refreshed every five minutes and no API key is required. [POKT](https://www.pokt.network) is a decentralized network that provides RPC access to popular Web3 systems and chains.
